# Open Graph 이미지 파일 안내

각 페이지의 초기 화면을 캡처한 이미지를 다음 경로에 저장해주세요:

## 필요한 이미지 파일

1. **og-home.jpg** - 홈페이지 (`/`)
   - Hero 섹션과 초기 화면이 보이는 이미지

2. **og-works.jpg** - 작품 목록 페이지 (`/works`)
   - "WORKS" 제목과 작품 그리드가 보이는 초기 화면

3. **og-faq.jpg** - FAQ 페이지 (`/faq`)
   - FAQ 제목과 SERVICE/ETC 카테고리가 보이는 초기 화면

4. **og-inquiry.jpg** - 문의하기 페이지 (`/inquiry`)
   - 문의 폼이 보이는 초기 화면

5. **og-privacy.jpg** - 개인정보처리방침 페이지 (`/privacy`)
   - 개인정보처리방침 제목과 초기 내용이 보이는 화면

6. **og-notice.jpg** - 공지사항 페이지 (`/notice`)
   - 공지사항 목록이 보이는 초기 화면

## 이미지 권장 사양

- **크기**: 1200 x 630px (Open Graph 표준)
- **형식**: JPG 또는 PNG
- **파일명**: 위에 명시된 파일명 그대로 사용

## 이미지 생성 방법

1. 각 페이지를 브라우저에서 열기
2. 브라우저 개발자 도구 사용 (F12)
3. 디바이스 툴바에서 1200x630 크기로 설정
4. 스크린샷 도구로 캡처
5. `public` 폴더에 저장

또는 온라인 도구를 사용하여 각 페이지 URL을 입력하고 Open Graph 이미지를 생성할 수 있습니다.
